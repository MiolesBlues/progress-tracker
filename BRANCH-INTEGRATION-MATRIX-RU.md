## Решение по расхождению `fix/v2-release-hardening`

Локальные-only commits: `2e24e13`, `53c79d1`, `9598d28`, `15b5945`. Remote-only commits: `884cb3b`, `fadb567`, `b5b3349`, `66cd2d5`, `a38df43`, `7fd66ae`, `33cf9cb`, `a541ec6`, `5ba4f3d`. Ни одна сторона не удалялась, force push/rebase не использовались. Training library migration, `src/lib/training-library.ts` и onboarding из локального template commit содержат те же версии, что каноническая база. Более поздний код добавил безопасное создание программ, fail-closed env contract, release schema checks и сетевые/аккаунтные тесты. Remote-only Vite изменения выбирали публичный backend константами, а изменения ProgramManager упрощали pending operations; их не переносили, поскольку это конфликтует с нынешними требованиями среды и retry safety.

## Неразрешённые уникальные UX-варианты

Палитра из `feature/light-blue-palette` не переносилась: текущий контраст и темы уже валидированы, а смена общего визуального языка требует продуктового решения. Ветка и все её commits остаются сохранёнными; перенос на main не рекомендуется до UX review.

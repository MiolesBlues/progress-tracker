TypeScript, SQL/unit tests и production build проверяют остальную совместимость. Override требует повторной оценки при обновлении/удалении legacy loader; Bun 1.4.3 записывает его в lockfile v3 ([документация Bun](https://bun.com/docs/pm/overrides)).
